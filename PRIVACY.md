# Privacy policy

FogForge does not collect, store or transmit any personal data. There is no telemetry, no tracking and no account.

FogForge connects to the internet only for these purposes:

- **Checking for app updates** – it reads the latest release information of this repository from GitHub (`api.github.com`).
- **Listing, previewing and downloading icon packs** – it reads release information and downloads files from the [fog-forge-packs](https://github.com/DetainedStudio/fog-forge-packs) repository on GitHub.

These requests contain no personal information. As with any website, GitHub receives your IP address when files are downloaded; see the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

Everything else happens locally on your PC:

- Settings, the pack cache and backups are stored in the FogForge installation folder.
- FogForge only changes the loose icon files in `Dead by Daylight\DeadByDaylight\Content\UI\Icons` after you click **Activate**, and keeps a backup of the originals. It never modifies the game's `.pak` files.
- Uninstalling FogForge (Windows Settings › Apps) restores the original icons and removes the program.
